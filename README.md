# Starwhisper

Installers and automatic updates for Starwhisper, a private, end-to-end encrypted chat overlay for Roblox.

Download the latest **Starwhisper-Setup-x.y.z.exe** from [Releases](https://github.com/Basementt/starwhisper-releases/releases/latest). Installed apps update themselves from here.
